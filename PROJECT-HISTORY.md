# Project history and attribution

The Firebase and Python projects originated in coursework with a mixture of personal work and starter material. Exact historical authorship of individual sections is not established; this portfolio does not claim all original code as independently authored.

The portfolio edition was expanded with AI assistance. The Python CLI adds SQLite persistence, date/time validation, overlap checks, and standard-library tests. Roomly adds a separate browser-based reservation demo. Project Desk adds a redesigned interface and local demo, safe text rendering, owner-scoped Firebase operations, rules, and setup instructions.

The networking documentation summarizes an existing lab; fresh hardware testing and screenshots have not been completed as part of the portfolio cleanup.

Each project's README describes its verification status and remaining work. No production records or credentials are included.
